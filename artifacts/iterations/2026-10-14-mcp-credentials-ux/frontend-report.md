# MCP 凭据管理前端改进

## 交付

- 将个人登录会话期限放入独立会话区；个人与管理员代签发 MCP 凭据均使用单独列表，列表显示名称、安全前缀、状态及北京时间的创建、到期、撤销时间。有效期已过的记录标记为“已过期”。
- 管理员可选择所属用户并查看、签发或逐条确认撤销。停用账号和待首次改密账号的签发控件禁用，并说明服务端限制。移除了用户管理表中原先用于 MCP 凭据的 prompt/alert 流程。
- 完整 token 只在签发响应后进入当前页面的一次性交付区，注明所属账号、名称、用途和到期时间；提供复制、手动选择复制及隐藏清除。列表刷新失败时仍保留此次 token，刷新不会再次签发。没有把 token 写入 URL、Storage 或持久日志。
- 使用 `Intl.DateTimeFormat` 固定 `Asia/Shanghai` 时间。账号切换立即清空交付区；账号、所选用户或异步复制操作发生竞态时，迟到响应不会恢复旧 token 或更新新账号的复制状态。迟到签发可能已在后端创建凭据，但界面不会向新账号发隐式撤销；管理员需回原用户列表核对并按需逐条撤销。
- 交付提示说明 MCP 地址由部署提供，Agent 使用 Bearer 凭据连接；管理员凭据绑定管理员权限，不应分发给普通用户。数据库只保存哈希，丢失后需要重新签发并撤销旧凭据。

## 角色视图补充

- 管理员不再看到重复的“我的 MCP 凭据”面板，也不再请求个人凭据列表；管理员在统一的“用户 MCP 凭据”区选择任何用户（包括本人）管理。reader 仍只显示个人凭据区。个人登录会话区独立保留。
- 明确说明“名称只用于备注，不代表所属账号”，管理员签发时以所选账号为准。
