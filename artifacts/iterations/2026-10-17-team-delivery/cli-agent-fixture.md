# Temporary MCP CLI and agent fixture

This fixture contains one generated private corpus, one generated bearer, and an in-memory Qdrant client. It serves a small synthetic document about a records-retention policy. It has no connection to project corpora, user identity stores, deployed services, or saved CLI configuration. A CLI `mcp list` pass proves configuration/transport discovery only; it does not prove a generated answer.

## Start and inspect the fixture

From PowerShell, set `$worktree` to this isolated checkout and use the main project interpreter:

```powershell
$worktree = 'C:\Users\Onebiter\.codex\worktrees\team-delivery-20261017\rag-project'
$python = 'E:\日常任务\rag-project\.venv\Scripts\python.exe'
$stateDir = Join-Path $env:TEMP ('wenjin-team-delivery-fixture-state-' + [guid]::NewGuid().ToString('N'))
$logDir = Join-Path $env:TEMP ('wenjin-team-delivery-fixture-log-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $stateDir, $logDir | Out-Null
$env:WENJIN_FIXTURE_STATE_DIR = $stateDir
$env:PYTHONPATH = Join-Path $worktree 'src'
$fixture = Start-Process -PassThru -WindowStyle Hidden -FilePath $python `
  -ArgumentList @('-m', 'tests.acceptance.team_delivery_mcp_fixture') `
  -WorkingDirectory $worktree `
  -RedirectStandardOutput (Join-Path $logDir 'stdout.log') `
  -RedirectStandardError (Join-Path $logDir 'stderr.log')
```

Wait for `fixture.json` to appear in `$stateDir`, then read it into `$fixtureDescriptor`. It contains the loopback MCP endpoint, synthetic token, one natural-language question, and only test-corpus metadata. Do not share its bearer beyond the isolated test task.

```powershell
$deadline = (Get-Date).AddSeconds(30)
while (-not (Test-Path (Join-Path $stateDir 'fixture.json')) -and (Get-Date) -lt $deadline) {
  Start-Sleep -Milliseconds 200
}
$fixtureDescriptor = Get-Content (Join-Path $stateDir 'fixture.json') -Raw | ConvertFrom-Json
```

The source is generated by `tests/acceptance/team_delivery_mcp_fixture.py`; do not show that source or this document to a model being evaluated. For an answer-quality check, give a fresh agent only the descriptor's endpoint/token and `query`, and ask it to answer with MCP evidence. The `query` asks about the default retention period and the shorter-lived exception. The expected text and source are intentionally not included here.

## Claude Code and OpenCode connection check

The checker writes both clients' configuration under a unique temporary directory and gives each process a temporary HOME/config/data/cache/state tree. It invokes Claude with `--bare`, strict MCP config, only `project,local` settings, and no session persistence. It invokes OpenCode with only the temporary HTTP MCP config, `oauth:false`, model-fetch/autoupdate disabled, and pure mode. It does not read global CLI config or credential files.

```powershell

& $python (Join-Path $worktree 'tests\acceptance\run_team_delivery_cli_checks.py') `
  (Join-Path $stateDir 'fixture.json')
```

Its task-only npm installation remains under `%TEMP%/wenjin-team-delivery-tools-20261017` because automatic approval rejected cleanup; set the example path to an installed executable on the machine performing the next check. Claude Code 2.1.296 discovered the temporary endpoint and reported **Pending approval (run claude to approve)**. This proves discovery only; it does not prove approval, a successful connection, or a tool call. No approval was granted. Do not retry the CLI check automatically.

The corrected Claude setup uses project config plus temporary local approval settings. After starting a fresh fixture, make an isolated empty project directory and write a `.mcp.json` containing only its synthetic loopback endpoint and bearer. Store project approval in that project's `.claude/settings.local.json`:

```powershell
$claudeProject = Join-Path $stateDir 'claude-project'
New-Item -ItemType Directory -Path (Join-Path $claudeProject '.claude') -Force | Out-Null
$mcpConfig = @{ mcpServers = @{ 'synthetic-wenjin' = @{
  type = 'http'
  url = $fixtureDescriptor.endpoint
  headers = @{ Authorization = "Bearer $($fixtureDescriptor.bearer)" }

Set-Content -LiteralPath (Join-Path $claudeProject '.mcp.json') -Value $mcpConfig -Encoding utf8
Set-Content -LiteralPath (Join-Path $claudeProject '.claude/settings.local.json') `
  -Value '{"enableAllProjectMcpServers":true}' -Encoding utf8

```

## Stop and remove the fixture

The server removes its generated corpus root and descriptor after it observes its own stop marker. The process and both CLI checks are temporary; no persistent services are installed. In the completed run, the stop marker was sent, the descriptor PID exited, and the loopback port stopped listening. The fixture is currently stopped and its descriptor was removed.

```powershell
New-Item -ItemType File -Path (Join-Path $stateDir 'stop') -Force | Out-Null
Wait-Process -Id $fixtureDescriptor.pid -Timeout 20
Test-NetConnection 127.0.0.1 -Port ([uri]$fixtureDescriptor.endpoint).Port -InformationLevel Quiet
```

The final command should return `False`. Keep the task-owned log directory for audit; do not recursively remove a path until its resolved location has been checked against the exact temporary directory created for that fixture.
